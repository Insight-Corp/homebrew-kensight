# homebrew-kensight

The Homebrew tap for `kensight`, the launcher that joins a machine to a Kensight fleet.

```
brew install insight-corp/kensight/kensight
kensight join <your Kensight address>
```

The launcher shows a short code. Someone signed in to Kensight approves it under Machines, Join Fleet, and the launcher then installs the worker from that Kensight. It holds no Kensight address of its own.
